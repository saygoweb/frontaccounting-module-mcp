**Goal:** A FrontAccounting module (`modules/mcp`) that serves FA to Claude.ai and Claude Code as a remote MCP server, through a new in-process `Executor` API of the GraphQL module.

**Architecture:** Three repositories. graphql gains `FA\GraphQL\Api\Executor` (contract 1.0) and a `read`/`write` scope claim on its tokens. FA's reusable CI workflow gains a shared Codecov upload. mcp is a Slim 4 front controller with a hand-written dual-era MCP protocol (ported from imscp-mcp), tools generated from the company's live GraphQL schema, and an OAuth 2.1 authorization server (ported from imscp-mcp) whose access tokens are graphql machine tokens.

**Tech Stack:** PHP 7.4–8.3 (Composer platform 7.4.33), Slim 4, slim/psr7, PHP-DI 6, webonyx/graphql-php 15, lcobucci/jwt 4 (graphql), PHPUnit 9.6, phpcs (PSR-12), PHPStan 1, FA CI image (`docker/ci/plugin-test.sh`), GitHub Actions, Codecov.

```php
<?php

namespace FA\GraphQL\Api;

use FA\GraphQL\Auth\Claims;
use FA\GraphQL\Config;
use FA\GraphQL\Error\ErrorFormatter;
use FA\GraphQL\Fa\Warnings;
use GraphQL\Error\SyntaxError;
use GraphQL\GraphQL;
use GraphQL\Language\AST\OperationDefinitionNode;
use GraphQL\Language\Parser;
use GraphQL\Type\Schema;
use GraphQL\Validator\DocumentValidator;
use GraphQL\Validator\Rules\QueryComplexity;
use GraphQL\Validator\Rules\QueryDepth;

/**
 * One GraphQL document, executed the way the API executes every document: the
 * token's scope, the depth and complexity limits, the error formatter, and
 * FrontAccounting's warnings beside `data`. GraphQLAction (HTTP) and Executor
 * (in-process) both run documents through this, so the two cannot drift.
 */
final class DocumentRunner
{
    public const READ_ONLY = 'This token is read-only.';

    private Config $config;
    private ErrorFormatter $formatter;

    public function __construct(Config $config, ErrorFormatter $formatter)
    {
        $this->config = $config;
        $this->formatter = $formatter;
    }

    /**
     * @param mixed $context the resolvers' context value (the request's container)
     * @param array<string, mixed>|null $variables
     * @return array<string, mixed> the response envelope: data, errors, extensions
     */
    public function run(Schema $schema, $context, string $query, ?array $variables, ?string $operationName, ?Claims $claims): array
    {
        if ($claims !== null && $claims->scope === Claims::SCOPE_READ && self::isMutation($query, $operationName)) {
            return ['errors' => [['message' => self::READ_ONLY, 'extensions' => ['code' => 'FORBIDDEN']]]];
        }

        // Per document: a warning belongs to the request whose work committed.
        Warnings::reset();

        $rules = DocumentValidator::allRules();
        $rules[QueryDepth::class] = new QueryDepth($this->config->maxDepth);
        $rules[QueryComplexity::class] = new QueryComplexity($this->config->maxComplexity);

        $result = GraphQL::executeQuery($schema, $query, null, $context, $variables, $operationName, null, $rules);
        $result->setErrorFormatter($this->formatter);
        $output = $result->toArray();

        // FrontAccounting's warnings about work that committed (Release 2 spec
        // section 3.2): the generated mutations return [<Entity>Type!]!, so they
        // travel beside `data`, not in it.
        $warnings = Warnings::all();
        if ($warnings !== []) {
            $output['extensions']['warnings'] = $warnings;
        }

        return $output;
    }

    /**
     * Whether the operation that would run is a mutation. A document that does not
     * parse, or names no runnable operation, is left to executeQuery to report.
     */
    private static function isMutation(string $query, ?string $operationName): bool
    {
        try {
            $document = Parser::parse($query);
        } catch (SyntaxError $e) {
            return false;
        }
        $operations = [];
        foreach ($document->definitions as $definition) {
            if ($definition instanceof OperationDefinitionNode) {
                $operations[] = $definition;
            }
        }
        foreach ($operations as $operation) {
            $name = $operation->name !== null ? $operation->name->value : null;
            if ($operationName === null ? count($operations) === 1 : $name === $operationName) {
                return $operation->operation === 'mutation';
            }
        }

        return false;
    }
}
```

```php
<?php

namespace FA\GraphQL\Api;

use FA\GraphQL\Auth\Authenticator;
use FA\GraphQL\Auth\Claims;
use FA\GraphQL\Auth\MachineTokenRepository;
use FA\GraphQL\Auth\MachineTokenService;
use FA\GraphQL\Config;
use FA\GraphQL\Error\Forbidden;
use FA\GraphQL\Error\InvalidToken;
use FA\GraphQL\Error\Unauthenticated;
use FA\GraphQL\Fa\FaSession;
use FA\GraphQL\RequestInfo;
use GraphQL\Type\Schema;
use Psr\Container\ContainerInterface;

/**
 * The supported way for another FrontAccounting module to use this API in the
 * same PHP process (contract 1.0; README "In-process API"). Every call runs as
 * the holder of a bearer token through exactly what POST /modules/graphql/ runs:
 * the Authenticator, the FrontAccounting session (SA_GRAPHQL), the scope rule,
 * the depth and complexity limits and the error formatter (DocumentRunner).
 *
 * FrontAccounting allows one company per PHP process, and so does this: a call
 * for a second company is refused UNAUTHENTICATED, as a second company is over
 * HTTP. Each call builds a fresh container, so nothing leaks between calls but
 * FrontAccounting's own globals.
 */
final class Executor
{
    public const CONTRACT_VERSION = '1.0';

    private Config $config;
    /** @var callable(Config, RequestInfo): ContainerInterface */
    private $containerFactory;

    public function __construct(Config $config, ?callable $containerFactory = null)
    {
        $this->config = $config;
        $this->containerFactory = $containerFactory ?? static function (Config $config, RequestInfo $request): ContainerInterface {
            return (require dirname(__DIR__, 2) . '/container.php')($config, $request);
        };
    }

    public static function create(?Config $config = null): self
    {
        return new self($config ?? Config::fromFile(dirname(__DIR__, 2) . '/config_graphql.php'));
    }

    public function execute(string $bearer, string $document, array $variables, string $clientIp, ?string $operationName = null): array
    {
        $c = $this->container($clientIp);
        $claims = $this->enter($c, $bearer);

        return $c->get(DocumentRunner::class)->run(
            $c->get(Schema::class), $c, $document, $variables === [] ? null : $variables, $operationName, $claims
        );
    }

    public function schema(string $bearer): Schema
    {
        $c = $this->container('');
        $this->enter($c, $bearer);

        return $c->get(Schema::class);
    }

    public function companies(): array
    {
        $this->session($this->container(''))->boot();
        $out = [];
        foreach ($GLOBALS['db_connections'] as $id => $connection) {
            $out[(int) $id] = (string) $connection['name'];
        }

        return $out;
    }

    public function authenticate(int $company, string $login, string $password): array
    {
        $session = $this->session($this->container(''));
        try {
            $session->loginWithPassword($company, $login, $password);
        } catch (Forbidden $e) {
            return ['status' => 'NO_API_ACCESS', 'login' => ''];
        } catch (Unauthenticated $e) {
            return ['status' => 'BAD_CREDENTIALS', 'login' => ''];
        }

        return ['status' => 'OK', 'login' => (string) $session->user()->loginname];
    }

    public function issueToken(int $company, string $login, string $scope, int $ttlSeconds, string $label): array
    {
        $c = $this->container('');
        // Becoming the user as a verified token would is what refuses an inactive
        // account or a role that lost SA_GRAPHQL since the user consented.
        $this->enterClaims($c, new Claims($company, $login, '', new \DateTimeImmutable('+1 minute')));
        $issued = $c->get(MachineTokenService::class)->issueSeconds($company, $login, $ttlSeconds, $label, $scope);

        return ['token' => $issued->token, 'jti' => $issued->jti, 'expiresAt' => $issued->expiresAt->getTimestamp()];
    }

    public function revokeToken(int $company, string $jti): bool
    {
        $c = $this->container('');
        $this->session($c)->openCompany($company);

        return $c->get(MachineTokenService::class)->revoke($jti);
    }

    public function tokenIsRevoked(int $company, string $jti): bool
    {
        $c = $this->container('');
        $this->session($c)->openCompany($company);
        $record = $c->get(MachineTokenRepository::class)->findByJti($jti);

        return $record === null || $record->revokedAt !== null;
    }

    public function database(int $company): array
    {
        $this->session($this->container(''))->boot();
        if (!isset($GLOBALS['db_connections'][$company])) {
            throw new \InvalidArgumentException("There is no company $company.");
        }
        $c = $GLOBALS['db_connections'][$company];
        $port = !empty($c['port']) ? $c['port'] : 3306;

        return [
            'dsn' => 'mysql:host=' . $c['host'] . ';port=' . $port . ';dbname=' . $c['dbname'] . ';charset=utf8mb4',
            'user' => (string) $c['dbuser'],
            'password' => (string) $c['dbpassword'],
            'prefix' => (string) $c['tbpref'],
        ];
    }

    private function container(string $clientIp): ContainerInterface
    {
        // In-process callers have applied TLS themselves; $clientIp is the end
        // client's address, which login throttling and refresh rows record.
        return ($this->containerFactory)($this->config, new RequestInfo(true, substr($clientIp, 0, 255)));
    }

    private function session(ContainerInterface $c): FaSession
    {
        return $c->get(FaSession::class);
    }

    private function enter(ContainerInterface $c, string $bearer): Claims
    {
        try {
            $claims = $c->get(Authenticator::class)->fromAuthorization('Bearer ' . $bearer);
        } catch (InvalidToken $e) {
            throw new ExecutorAuthException(ExecutorAuthException::UNAUTHENTICATED, $e->getMessage(), $e);
        }
        if ($claims === null) {
            throw new ExecutorAuthException(ExecutorAuthException::UNAUTHENTICATED, 'A bearer token is required.');
        }
        $this->enterClaims($c, $claims);

        return $claims;
    }

    private function enterClaims(ContainerInterface $c, Claims $claims): void
    {
        try {
            $this->session($c)->enter($claims);
        } catch (Forbidden $e) {
            throw new ExecutorAuthException(ExecutorAuthException::FORBIDDEN, $e->getMessage(), $e);
        } catch (Unauthenticated $e) {
            throw new ExecutorAuthException(ExecutorAuthException::UNAUTHENTICATED, $e->getMessage(), $e);
        }
    }
}
```

`fromAuthorization('Bearer ' . $bearer)` with an empty or whitespace bearer: treat `trim($bearer) === ''` as UNAUTHENTICATED "A bearer token is required." before calling it.
